# Support

Ask a question or start a discussion in the relevant repository:

- [majorcontext/gatekeeper](https://github.com/majorcontext/gatekeeper/discussions)
  has GitHub Discussions enabled. Use it for a question or open-ended
  discussion.
- Moat, Keep, Harness, and Bailey do not have Discussions enabled. Open an
  issue on the relevant repository instead.

Report a suspected security vulnerability through private vulnerability
reporting, not through Issues or Discussions. See `SECURITY.md`.
